# FitTrack Pro – Smart Workout & Fitness Tracker

## 🚀 Overview
FitTrack Pro is a full-featured fitness tracking mobile application built using React Native and Expo. It helps users track workouts, follow preset routines, monitor progress, and improve their fitness journey.

---

## 🔥 Features
- 🏋️ Workout tracker (sets, reps, weight)
- 📋 Preset routines (Push / Pull / Legs)
- 📊 Persistent workout history (AsyncStorage)
- ⏱️ Smart rest timer (custom + templates)
- 📚 Exercise library with search & filters
- 📈 Real-time dashboard with live updates

---

## 🧠 Tech Stack
- React Native
- Expo
- TypeScript
- AsyncStorage
- Git & GitHub

---

## 📱 How to Run
1. Clone the repository:
   git clone https://github.com/arnold0010/project.git

2. Install dependencies:
   npm install

3. Start the app:
   npx expo start

4. Scan QR using Expo Go
